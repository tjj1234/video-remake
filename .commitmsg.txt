feat: 模型固定为三模型链，各带独立参数适配器

用户不再选择模型/时长/分辨率，引擎固定按 Wan 2.7 r2v -> MiniMax Hailuo 2.3
-> Kling v3 运镜 的顺序尝试，失败自动降级。

关键修正：PT 视频 API 不是一套统一契约。三模型在端点、字段名、枚举值上
完全不同，之前「全部走 /v1/videos」的假设是错的：
- Wan 2.7 r2v: /v1/videos, model, media[reference_video], size 480/720/1080P
- MiniMax Hailuo 2.3: /v1/videos, image 必填, seconds 仅 6/10, size 仅 768P/1080P
  (10s 时 1080P 不可用)
- Kling v3: /kling/v1/videos/motion-control, model_name, image_url 必填,
  video_url, character_orientation, 无 size/seconds, 返回 Kling 原生格式

新增:
- adapters.mjs  三模型各自适配器，把「原片时长/尺寸」夹到各模型合法枚举值
- probe.mjs     ffprobe 探测 + ffmpeg 抽帧（浏览器版用 video+canvas 等价实现）
- adaptertest.mjs  44 项参数适配断言

时长与尺寸：按原视频就近取合法值（Wan 可精确到秒；MiniMax 只能 6/10；
Kling 继承参考视频），不再声称精确复刻。Seedance 全系三层拦截。

测试: 104/104 通过 (44 + 28 + 32)
